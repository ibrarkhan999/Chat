## 🛠️ Getting Started

### Prerequisites

Make sure you have installed:

- Node.js & npm/yarn  
- React Native CLI  
- Android Studio / Xcode (for emulators)  
- CocoaPods (for iOS)  

---

### Installation

1. Clone the repository:

```bash
git clone https://github.com/ibrarkhan999/Chat.git
cd Chat

# Using npm
npm install

# Or using yarn
yarn install

cd ios
bundle install
bundle exec pod install
cd ..

# Using npm
npm run android

# Or using yarn
yarn android

# Using npm
npm run ios

# Or using yarn
yarn ios


Chat/
├─ android/           # Android native code
├─ ios/               # iOS native code
├─ src/               # App components, screens, styles
├─ App.jsx            # Main app entry
├─ index.js           # App registration
├─ package.json       # Project dependencies
└─ README.md          # Documentation
